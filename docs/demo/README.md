## 资料与本机数据

Git 跟踪文字报告、任务说明及经检查的摘要。数据库、模型配置、凭证、依赖、浏览器资料、原始日志、截图和历史源码 zip 在本机保留。报告中的本地证据链接指向索引，用 run-id 和原文件名追溯，不代表 GitHub 已包含原始证据。

迁入 Git 时已将个人目录替换为 `${BEEFTV_REPO}`（源码检出目录）、`${WORKSPACE}`（早期父级工作区）及 Windows 安装路径占位符，并移除私人历史会话定位和操作员账号。历史命令如使用占位符，应先按当前机器明确配置；迁入前原文在原开发机的 Git 忽略目录留档。
