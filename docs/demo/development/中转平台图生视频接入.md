# Predictions 中转图生视频

当前中转的 MiniMax H3 系列使用独立协议 `predictions-h3-video`（设置中显示 **Predictions MiniMax H3**）。不能按模型品牌选择原生 `minimax-video` 协议：两者的路径、请求包装和响应不同。

渠道沿用实际中转根地址和现有凭据。文本、图片模型保留各自的协议；只给对应视频模型选择新协议。实现位于 `plugin-packages/predictions-h3-video/` 和后端 `generation/predictions_upload.go`。

生成时，后端先从当前用户有权限的资源读取参考图，上传到同渠道的 `POST /api/v1/files`，从 `data.list[].url` 获取公开链接，再提交 `POST /api/v1/predictions`。不需要用户配置对象存储或手动填写参考图网址。原画布资源保留，只有任务执行时的参考参数被转换成 URL。此渠道的上传结果公开可读，与中转文档一致。

视频提交结构为 `{model,input:{prompt,...}}`，携带稳定 `Idempotency-Key`；随后每 3 秒查询 `GET /api/v1/predictions/{task_id}`。成功从 `data.outputs` 取视频，非零业务 code 保留失败语义。上传失败会在创建视频前停止。

| 模型 | 时长 | 分辨率 | 输入 |
|---|---|---|---|
| `minimax-h3` | 5～15 秒 | 768P、2K、4K | 首尾帧，或图片/视频/音频参考 |
| `minimax-h3-max` | 5～15 秒 | 480P、768P、1080P | 首尾帧，或图片/视频/音频参考 |
| `minimax-h3-max-turbo` | 5～15 秒 | 480P、768P、1080P | 文字或首尾帧，最多两图 |

每文件最多 20 MiB；基础 H3/Max 参考图最多 9 张、视频/音频各 3 个，合计最多 12 个。首尾帧与参考素材不能混用，尾帧必须有首帧，参考音频必须搭配图或视频。帧模式不发送比例，提示词最多 7000 字符；不发送中转 schema 没有声明的水印、音频生成开关。

以上参数来自本轮只读查询的 `/api/v1/models/{id}`。若平台修改 schema，应重新核对并更新对应模型配置。

## 取消与修改提示词

生成启动后，输入区右侧的生成箭头变为方形取消按钮；准备参考素材、等待任务回执和生成期间均可点击。等待回执时显示“正在取消生成”，随后对同一任务发送取消，不丢弃其编号或重新提交。取消后保留当前编辑的提示词；未提交的准备操作可以修改后再生成。取消失败或原提交无法确认时保留原任务，先查询其状态。

本地任务取消不代表供应商停止计费。当前提供的 Predictions 接入文档没有撤销任务接口，本协议不猜测取消路径；上游已受理的 H3 请求仍可能继续生成和计费。关闭画布只停止页面监听，不会自动取消后台任务。

## 本地构建

新协议与其余插件一样，以 `.beeftv-plugin` 包随客户端安装。重新生成该协议源码/文档：

```bash
node plugin-packages/generate-catalog.mjs predictions-h3-video
```

首次从源码准备本机插件包，在插件目录运行：

```bash
cd plugin-packages/predictions-h3-video
python3 -m zipfile -c ../predictions-h3-video.beeftv-plugin manifest.json README.md docs/interface.md
```

返回仓库根目录，通过 `scripts/update-local-beeftv-app.sh` 更新客户端。源文件提交到 Git，生成的插件包与运行凭据不提交。
