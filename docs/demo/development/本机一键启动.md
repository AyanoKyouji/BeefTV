# Mac 日常开发启动

在仓库根目录执行 `make dev`，或在 Finder 双击根目录的 `启动开发.command`。启动器会编译 Go 后端、启动 Vite，并打开浏览器：

```bash
make dev
```

默认地址为 <http://127.0.0.1:3000>。服务在后台运行，关闭终端或浏览器后仍继续运行。重复执行 `make dev` 会打开已有实例。前端源码修改由 Vite 热更新；修改 Go 后端或 Agent 宿主后执行 `make restart`。

| 命令 | 用途 |
| --- | --- |
| `make dev` | 启动并打开浏览器 |
| `make stop` | 停止本启动器管理的前后端及 Agent 宿主 |
| `make restart` | 重新编译后端并重启 |
| `make status` | 查看服务状态、地址和数据目录 |
| `make logs` | 查看并持续跟随日志，Ctrl+C 只退出日志 |
| `make help` | 显示命令说明 |

## 环境与数据

需要 Python 3.9+、Go（满足 `backend/go.mod`）、Bun，以及 `scripts/package-agent-host.mjs` 中钉选版本的 Node。启动器优先使用 `.local/tools` 中已有的 Bun 和对应版本 Node，再查找 PATH；也可以用 `BEEFTV_DEV_GO`、`BEEFTV_DEV_BUN`、`BEEFTV_DEV_NODE` 指定可执行文件的完整路径。不会自动下载运行时。

缺少前端或 Agent 依赖时，会自动执行 `bun install --frozen-lockfile`；已有依赖直接复用。每次启动还会用仓库脚本准备官方协议插件包（需系统 `sh`、`find`、`sort`、`zip`），供图片等协议加载；插件包属于忽略的构建产物。首次编译或安装依赖需要更长时间。依赖锁文件变化后，请在对应目录重新执行安装命令。

日常数据固定保存在 `.local/project-workbench-debug/daily`，停止或重启不会清空。首次运行是空工作区，可在“模型配置”中配置渠道；若本机已由开发者迁入加密模型配置，则沿用该配置。启动器只写入当前检出的 Node / Agent 宿主路径，不改动模型凭据。日志及进程记录保存在 `.local/dev`，编译缓存放在 `.local/cache`，这些内容均不提交 Git。

这套入口使用正式 `backend/cmd/server` 和 `agent-host/server.mjs`，以浏览器完成日常调试。它仅监听本机回环地址。后端及私有 owner 凭据就绪后，Vite 在服务端读取该凭据，仅向 `/api/ops`、助手 UI 会话及客户端管理入口转发；其他 API 保持现有浏览器合同，避免将模型配置误标为外部发现后脱敏。owner 凭据不写入浏览器代码、URL 或仓库，也不放入 `VITE_` 环境变量。启动就绪检查还会核对经代理的 `/api/ops`，避免只检查页面或工作区引导却漏掉编辑授权。原生 Wails 窗口、系统集成和 Windows 行为仍按阶段另行验证。

## 可选设置与排障

```bash
# 不自动打开浏览器
BEEFTV_DEV_OPEN=0 make dev

# 默认端口被其他程序占用时，换用两个不同端口
BEEFTV_DEV_WEB_PORT=3001 BEEFTV_DEV_BACKEND_PORT=8081 make dev

# 使用另一个隔离数据目录（必须仍在开发数据根目录内）
BEEFTV_DEV_DATA_DIR="$PWD/.local/project-workbench-debug/my-test" make dev
```

已有实例运行时会继续打开原实例；修改设置前先执行 `make stop`。端口被其他进程占用时启动器会报错，不会关闭其他程序。启动失败时执行 `make logs` 查看日志；后台某个服务退出时，启动器会停止另一个服务，避免残留。请勿直接公开日志，日志可能包含本机业务信息。

这与安装版的数据目录分离。需要更新原生 Mac 安装版时，仍使用仓库规定的 `scripts/update-local-beeftv-app.sh`。
