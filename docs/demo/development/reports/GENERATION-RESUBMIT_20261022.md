# 取消后在同一节点重新生成

## 问题与处理

用户取消后，旧节点仍显示失败及“暂勿重复生成”，按钮虽然恢复箭头，提交逻辑仍优先查询旧 operation ID，不能按新提示词生成。

现在已确认取消的空节点恢复待生成状态，已有结果保留，取消不再显示为生成失败；清除上一轮重复提交指纹，允许原提示词直接再发一次。明确取消但无法取得回执时，将旧编号与停止时间保存为节点的 `stoppedGenerationSubmissions`，清除当前提交锁，允许新的独立生成。编辑稿、参考素材和原媒体保留；节点面板提供“查看上次请求”只读查询，旧状态保持 unknown，不伪造上游撤销。

任务更新与结果消费同时核对当前操作身份及已停止记录，迟到的旧状态和结果不会回填到正在生成的新节点。未主动取消的未知提交仍按原身份恢复，不自动换编号重提；取消失败且已知 Task 仍运行时，保留其状态和错误提示。

上游已受理的请求仍可能继续生成和计费。本轮没有新增供应商撤销接口，也没有调用收费模型。
