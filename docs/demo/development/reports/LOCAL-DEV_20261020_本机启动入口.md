## 交付内容

仓库根目录新增 `Makefile` 与可双击的 `启动开发.command`，统一调用 `scripts/local-dev.py`。支持启动、停止、重启、状态和日志；后台运行，重复启动复用已有实例，进程标识校验避免停止无关进程。端口冲突或构建失败会报错；前后端之一退出时清理另一进程。状态记录原子替换，避免启动期间读到半写入内容。

启动链使用正式 `backend/cmd/server`、Vite 与 Go 管理的官方 Agent 宿主；开发 UI 引导只在此次本机服务进程开启，前后端仅监听回环。固定日常数据目录为 `${BEEFTV_REPO}/.local/project-workbench-debug/daily`，与既有阶段验收目录及安装版数据分离。本机已一次性复制既有加密模型配置及配套密钥到日常目录，启动脚本和 Git 中不包含模型凭据。

使用说明见[本机一键启动](../本机一键启动.md)，快速开始和 Demo 索引已添加入口。

## 实测结果

| 验证 | 结果 |
| --- | --- |
| `make dev`、`make status` | 正式 Go 后端和 Vite 就绪；前端代理可完成本地工作区引导 |
| 普通 Chrome 会话 | 无测试鉴权头，首页可用；通过 UI 创建画布，API 确认持久化 |
| Agent 面板与状态 | 正常签发 UI 会话，Go 拉起宿主；`available=true`，选择既有 DeepSeek 模型 |
| 重复启动与 `.command` 入口 | 复用原启动器 PID，无重复服务 |
| `make stop` | 前端、后端及已拉起的 Agent 子进程退出，监听端口释放 |
| 外部进程占用端口 | 明确失败，不关闭占用进程，不产生启动实例 |
| 后端构建失败注入 | 明确失败，不残留运行实例 |
| 后端提前退出注入 | Vite 随之退出，运行状态文件清理 |
| `make restart` 与立即重启 | 编译后恢复服务；已修正 TIME_WAIT 被误判为端口占用的问题 |
| `make logs` | 正常输出；Ctrl+C 后服务保持就绪 |
| 进程重启后全新浏览器 | 原画布仍在业务数据库中，页面恢复，助手重新就绪 |
| Python / Bash 语法、Git diff 空白检查 | 通过 |

本次不发送模型聊天请求，浏览器观测到 `/api/assistant/chat` 调用数为零。原始运行日志、浏览器脚本、截图与结果保留在本机忽略目录 `.local/dev`；其中端口占用、构建失败和进程退出报错属于明确的故障注入，后续启动和恢复验证通过。

本次复用已安装的依赖验证启动；缺依赖时的自动安装分支未通过删除现有依赖另行实测。Mac 原生 Wails 窗口、Windows、媒体生成与付费模型业务验收不属于此次启动入口验证范围。
