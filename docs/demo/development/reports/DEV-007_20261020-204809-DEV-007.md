首次将 owner 附到所有 API 时，模型配置按外部发现规则脱敏，前端误判没有 API Key，尚未创建任务。缩小传递范围后，自定义渠道凭据读取、节点编辑保存及真实任务提交均正常。owner 采用非 `VITE_` 私有环境变量提供文件位置，不进入前端模块或仓库。
