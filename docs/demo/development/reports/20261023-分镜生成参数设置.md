# 分镜图片与视频生成参数设置

## 问题与改动

脚本节点原先只能选择分镜图片和视频模型，不能直接设置生成参数；生成目标还可能沿用旧节点的参数。

- 脚本节点工具栏、展开分镜板的两个模型选择器旁，复用现有模型参数面板。
- 图片按模型能力展示尺寸、比例、分辨率或质量、透明背景；每镜一张，不展示多图数量设置。
- 视频按模型能力展示分辨率、比例、秒数、声音与水印，并提供 MiniMax H3 提示词增强和种子设置。
- 视频默认使用每镜计划时长，并按模型能力归一化。选定秒数后统一用于接下来的视频生成，可点击「按各镜头时长生成」恢复；不改写脚本的计划时长。
- 参数独立存于脚本 metadata：`storyboardImageSettings`、`storyboardVideoSettings`。切换模型重置对应参数，另一类参数与文字模型保持原值。
- 首次生成、批量补齐、直接视频、首帧视频与重新生成使用相同参数解析；提交前读取最新脚本。重新生成仍创建新目标，已完成结果保留。
- 参数选择不触发生成；普通生成继续直接提交，不增加确认弹窗。
