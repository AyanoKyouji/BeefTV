# Agent 直接生成与依赖顺序

## 需求与实现

用户要求 Agent 操作不再逐次确认生成，并修复移动节点后整份提案失效的问题。当前内置宿主改用 `canvas.generation.start`，旧提案卡只读显示，不再出现“生成 / 先不用”按钮或“等待确认”。普通节点的手动生成入口保留。

直接提交读取当前节点、模型参数与真实参考资源，仅核对提交提示词与当前草稿，不依赖旧的整画布 revision。任务接纳、节点任务标记和操作回执在同一事务完成；官方 Durable 使用稳定工具调用身份重放，不另建执行循环。模型密钥只在后端解析和受保护任务输入中使用，工具回执只返回任务标识和状态。

按用户要求的先后依赖执行：首图成功交付并绑定后，才按实际图片编写分镜；分镜图使用已生成参考，成功交付后才作为视频参考。Agent 通过现有任务查询等待，不能将 queued 当作成功，也不能自动重交收费任务。后端拒绝空/失败/正在生成的参考节点，产物绑定继续使用原有归属与目标校验。失败、取消或目标删除时停止后续依赖，保留已完成部分。用户只要求计划或先不生成时，不提交生成。

保留项目成本约束：不使用 Seedance / Seedream，视频按指令选择已配置的 minimax-h3；已保存模型不可用时报告，不偷偷改选。节点每次对应一个产物，多张图片通过多个独立节点实现。

单轮默认模型请求/工具步骤上限由 40 调整为 96，为创建、配置、连线及多阶段查询留出空间；显式环境变量与总预算继续生效。达到上限仍会停止并保留已完成结果，可发送继续消息按原任务恢复，不自动重新付费生成。

## 验证

- 官方 Durable、操作桥与提示词专项 47 项通过，包括本机替身模型驱动的首图 → 等待/绑定 → 分镜 → 分镜图 → 等待/绑定 → 视频 → 等待/绑定，无前端确认；此用例验证宿主工具流程，不代表真实模型画面质量或真实供应商全链路验收。
- Go 真实单连接 SQLite 接纳验证通过：移动节点后可生成、提示词改变拒绝、未就绪参考拒绝、重复调用回读原任务、并发重复拒绝、加密凭据、真实本地图片交付后可提交 H3 参考视频、回执失败时事务回滚。无真实上游请求。
- 操作目录、权限、轮次与回执相关专项通过；前端状态/流/历史卡测试 73 项及类型检查通过。
- 初次扩大到全部 operations 测试时，环境没有 PATH 中的 ffmpeg，既有媒体用例失败；新能力目录计数相应更新后，改为本次涉及的专项范围通过，不宣称完整媒体 suite 通过。

本机忽略证据目录 `.local/agent-direct-20261022/` 保存测试、构建和原生核对；业务画布、模型配置、运行令牌不提交。本轮没有调用真实收费模型。

## 使用

更新客户端后，在原对话发送“按刚才的完整要求继续，先检查已有任务与成品，保留已完成结果，按依赖顺序直接生成”。历史方案不会自动执行，也不会因升级自行扣费。也可以新建对话完整描述人物、分镜数量、时长和模型要求。正常移动节点不影响生成；修改提示词或删除参考时，Agent 需要重新读取最新内容。
