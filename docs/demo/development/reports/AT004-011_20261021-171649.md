原第三阶段 AT006 要求手动修改后使用最新创作内容，并没有要求新增“全屏表格勾选行就是 Agent 当前镜头”的能力。T504 仍要求核对最新内容、正确目标、实际生成输入和归属。

本轮实际勾选全屏表格第二行：第一行未勾选，批量“生成分镜图”按钮启用。该选择属于表格内部的批量生成输入，关闭后没有写入业务文档。回到 Agent 侧栏显示“已选 1 个节点”；明确发送“只读取当前选中脚本的第二个镜头，不生成图片”，捕获的正式前端请求只有脚本 `selectedNodeIds`，没有行选择字段。请求在进入后端前拦截，未执行模型，所以它只证明请求范围，不证明模型本轮读取或理解成功。

本地源码与既有上下文测试对应：后端以轮前持久快照构造 `storyboardContext`，携带选中的 Script、稳定 Row ID 及发送时顺序；显式“第二镜”可按该快照定位，不能把表格勾选当作隐含行授权/目标。节点选择也可以从当条消息移除。

结合 [DEV-005](DEV-005_20261020-171515-DEV-005.md) 的最新保存时序、[DEV-006](DEV-006_20261020-202155-DEV-006.md) 的重排/删除/不同脚本稳定目标以及 [DEV-018](DEV-018_20261021-152916.md) 的真实最新输入→明示第二镜→正式归属，原 AT006 的 Mac 功能范围已有证据，本轮关闭的是选择口径疑问。没有新验证省略镜头位置的含糊指令，也没有扩大为“仅勾选行就能自动理解当前镜头”。最终同构建真实闭环和 Windows 平台验收仍待执行。
