## 发现并修复（Windows 侧）

### W3 — 采集器文本字段读取缺陷（需 Mac 侧合入）

- **现象**：两轮文本节点 `content: ""`，操作员确认 UI 已填入。
- **根因**：采集器读 `node.metadata.content`；`f84d5a1` 数据模型下文本正文实际存于 `composerContent`（回退 `prompt`），`content` 仅在生成完成后写入。UI 依据：`web/src/components/canvas/canvas-node-prompt-panel.tsx:88`。
- **修复**（采集器一行，DEV-017 包根，未动 DEV-003 原件）：

```diff
-      ...(node.type === 'text' ? { content: node.metadata?.content } : {}),
+      ...(node.type === 'text' ? { content: node.metadata?.composerContent ?? node.metadata?.prompt ?? node.metadata?.content } : {}),
```

- **建议**：Mac 侧将此修正合入 `Inspect-Saved-Project.mjs`，并更新 `docs/demo/development/handoff/DEV-017/README.md` 的调用示例（补 `--db` / `--title`）。
