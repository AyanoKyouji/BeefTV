# 分镜板交互改进

日期：2026-10-22。范围：脚本节点与展开编辑区域的第一轮交互改善。

## 本次实现

- 画布中的长文本表格改为镜头卡片，显示图片缩略图、画面描述、景别、计划时长、参考素材以及图片/视频状态。
- 常驻“补齐分镜图”“生成镜头视频”“合并成片”，不再以更多菜单作为主要生成入口。
- 点击镜头铅笔直接进入相应镜头的编辑与预览；展开区域默认卡片，保留表格视图、筛选和选择范围提示。
- 镜头详情优先显示画面、台词、时长与景别，生成提示词和其他专业字段折叠；支持上移、下移、复制和删除镜头。
- 图片可点击放大，视频点击后才打开播放器；卡片不批量挂载视频解码器。输入参考与生成产物分开呈现。
- 取消、单镜生成、素材定位与批次停止复用当前操作入口，未新增任务执行器或数据模型。主工具栏生成只传递未完成镜头；全部结果已完成后不再用历史失败批次覆盖当前进度。
- 卡片行高与画布连线命中、吸附及绘制共用布局常量；新节点默认显示两镜高度，更多镜头滚动查看。

## 验证

- 42 项针对性测试通过，覆盖卡片完成/失败/取消/批次延迟状态、连线滚动及重排、素材关联、保存后提交与原有面板边界。
- TypeScript 检查通过。
- Mac 本地发布检查及原生构建通过；通过正式更新脚本更新已有 `/Applications/YUNTV.app`，保留工作区数据与模型配置。
- 原生深色界面：更新后重新打开已有项目，3 镜与 3 张图片恢复，当前图片进度为 3/3，历史失败批次不再覆盖当前进度。
- 从画布点击第二镜直接打开第二镜详情；筛选“背影逐渐变小”后只显示第三镜，详情及生成范围同步切换为该镜；清空筛选恢复完整列表。
- 图片放大与关闭成功，竖图在固定预览区域内保持比例。首次原生验收发现弹窗内容已存在但进场动画未显示；局部停用分镜板及素材预览的进场动画后，实际截图显示正常。
- 将第二镜上移再下移，原顺序恢复，图片仍保持 3/3；临时填写台词，切到表格确认内容一致，再清空恢复原文并保存。最终保留原镜头顺序、原台词和已有图片，客户端停留在第二镜详情。
- 表格勾选一镜时，操作范围明确显示“已选 1 镜”；本轮没有点击真实生成、视频或合并提交按钮。视频实际播放未补验，当前项目没有镜头视频；新取消按钮的运行/停止状态由零模型测试覆盖。
- 浅色原生界面未在本轮切换复验；组件使用现有主题变量。Windows 回归留待平台验收。

## 整条点击选中补充

按用户反馈扩大选择区域：点击分镜条目的文字、状态或空白处即可打开/选中对应镜头。内部按钮与表单独立处理，预览弹窗通过 React Portal 冒泡的点击也不会误选镜头，铅笔入口继续保留。

5 项既有卡片检查及 Mac 发布检查、构建通过，已更新本机客户端。原生实测：点击画布第二镜正文直接打开第二镜详情；在分镜板点击第一镜正文、第二镜条目，详情与高亮正确切换；保持第二镜选中时预览第一镜图片，关闭后仍选中第二镜。本轮未编辑内容或重排镜头，未点击生成按钮。

本轮构建与测试摘要分别为 `.local/storyboard-card-click-build-20261022.log`、`.local/storyboard-card-click-tests-20261022.log`。

## 鼠标拖动与方向键排序补充

- 卡片视图中，选中镜头后可按住左键拖放到另一镜头前/后；显示插入线，松开时提交顺序，拖到列表外或取消不修改顺序。内部预览、生成等按钮不作为排序拖动起点。
- 镜头列表获得焦点后，`↑` / `↓` 将选中镜头向前/后移动一位；打开卡片编辑区会聚焦列表，点击条目或铅笔也保持键盘可用。输入框、下拉框等保留自身方向键行为。
- 鼠标、键盘和原上/下移按钮复用同一排序函数，只更新数组顺序和展示序号，不改镜头 ID、内容或素材归属。落点按当前镜头数据计算，不用拖动开始时的媒体快照覆盖后续更新。
- 20 项排序、卡片及关联测试通过；另有 5 项独立事件回放测试，覆盖拖动前不写入、落点提交、拖动中素材更新、取消、控件边界和键盘边界。类型检查与 Mac 发布检查、构建通过。
- 原生键盘实测：选中第二镜，`↑` 移到第一位，`↓` 恢复第二位，当前图片保持 3/3；台词输入框内 `↑` / `↓` 没有重排。按本轮开始时的镜头顺序恢复，没有创建生成任务。
- 最终客户端复验：从画布打开第二镜后，无需再点击列表即可直接按 `↑` / `↓` 排序；恢复本轮开始时顺序后保存，画布显示“已保存在本地”。
- **验证限制：**原生自动拖放工具使用应用路径及 Bundle ID 分别尝试，均返回 `noWindowsAvailable`；未获得真实鼠标拖动成功证据。拖放路径通过实际组件事件回放验证，不能替代原生手势验收。浅色与 Windows 手势未复验。
