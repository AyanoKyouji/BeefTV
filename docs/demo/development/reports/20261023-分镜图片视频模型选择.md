# 分镜图片视频模型选择

## 实现

- 在脚本节点工具栏及展开分镜板提供独立的图片、视频模型选择，复用现有 ModelPicker，按模型能力过滤已配置渠道。
- 以节点 metadata 的 `storyboardImageModel` / `storyboardVideoModel` 随画布保存；不改全局默认或文本拆镜模型。没有节点选择时沿用当前对应类型默认模型。
- 单镜、批量补齐及重新生成共用选择来源，覆盖图片、直接视频、首帧视频。目标节点明确写入所选模型，已有草稿不会用旧模型覆盖选择；模型变化复用现有参数失效逻辑，清除旧模型的尺寸、质量等参数。
- 完成的旧素材保留；已入队任务使用其目标节点中已记录的模型，之后更改脚本选择不修改这些任务。
- 确认期间模型改变则不提交旧选择；失效模型不静默回退到另一模型。

## 验证

- 17 项独立流程检查通过，覆盖首次生成及重新生成的三条媒体路径、批量补齐、确认模型与排队目标一致、参数失效、选择序列化、全局设置不变、确认期间切换和模型失效。
- 24 项卡片、素材关联、目标隔离及模型配置检查通过。TypeScript 检查通过。
- 检查均使用本地模拟任务，未调用收费模型。
- Mac 发布检查、原生构建及正式应用更新通过。原生深色界面验证：脚本节点工具栏及展开分镜板均显示独立选择器；图片菜单只列已配置的 flux-3-image，视频菜单只列已配置的 minimax-h3，两种能力未混入文本模型。
- 分别选择当前图片、视频模型后保存，返回主页再打开项目，两个选择器恢复为 Flux / H3，拆镜仍为 deepseek-flash，已有图片仍为 3/3。展开分镜板点击单镜视频生成，确认正确显示 1 个任务、minimax-h3；取消后返回分镜板，无新媒体节点或任务。
- 当前原生配置各只有一个图片、视频模型，跨模型切换用上述流程测试覆盖；未添加或更改用户的模型渠道配置。浅色及 Windows 未复验。
