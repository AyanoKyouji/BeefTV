## 问题与修复

空图片节点的工具定义已有 `uploadImage` 和正式上传处理器，但图片主工具栏只保留局部重绘，图片设置又只筛选 `replace / resize / node-lock`，导致已有上传工具不出现在菜单中。浏览器实际选择空节点后仅显示图片设置，找不到上传操作，与本地筛选逻辑一致。

仅将 `uploadImage` 纳入图片设置筛选。复用原文件选择、上传、资源落盘和素材保存逻辑，不添加另一套上传接口，不改变有图节点的替换处理。实际验证用 Shift 只选中空图片节点，在“图片设置 → 上传图片”中选取文件；生成编辑器和工具栏的显示约定未调整。

本轮手动创建项目、脚本、两行及两个分镜图片节点，均通过 UI 操作；没有预置图片成功结果、生成回放或后台 Agent 代办。脚本默认三个空行，经 UI 删除一个，仅保留两个明确目标。导入发生于修复后的 Vite 源码，提交后重启到同一修复版本再执行真实生成和恢复。
