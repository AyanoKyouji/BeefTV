# 移除生成确认弹窗

按用户要求，点击生成即开始，不再要求重复确认提交或计费。

## 调整范围

- 脚本拆镜、分镜图、直接视频、首帧视频、动作板，以及对应重新生成入口。
- 批量创作表的单行与批量提交。
- 普通图片、视频、文本、音频执行器中的相同内容再次生成确认。
- 任务重试与生成过程中的渠道输出比例确认，改用非阻断消息。

必要的输入填写、组件安装、删除内容、章节已有分镜的不可撤销替换、停止任务及恢复历史结果写入不属于普通生成提交确认，保持原操作。后端任务准入和执行归属校验继续执行。

## 状态与验证

沿用生成提交锁，脚本图片、两种视频、动作板及批量创作均防止同一时刻重复点击入队。所选模型、参考素材、旧结果保留、画布完整保存、取消与过期操作阻断继续生效。没有通过自动点击正式客户端生成按钮来触发收费模型。

首次客户端更新被自动审批拒绝：当时还移除了章节已有分镜的不可撤销替换确认，超出普通生成确认调整范围。已完整恢复该覆盖确认及其原有说明、回归检查，采用保留破坏性操作确认的范围重新更新。
