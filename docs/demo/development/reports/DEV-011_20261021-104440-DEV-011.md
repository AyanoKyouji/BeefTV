## 发现与修复

生成中重排的既有实现按 Row ID、imageNodeId 和任务目标 Node ID 保持归属，没有按完成时镜头序号回填。但执行中修改图片提示词后，旧输入的产物仍被该行当作当前图片使用：原版受控场景 `stale-before` 实际复现，完成后仍保留旧 imageNodeId。

现在，图片有效输入变化时会解除该行到旧图片的关联及输出连线，原图片节点、执行中的任务和最终产物保留。有效输入优先使用图片提示词，未填写时使用剧情描述；单纯重排、台词修改、未改变有效输入的剧情修改及首尾空白变化保留关联。明确替换图片不被当成旧图片回填。

前端行编辑与现有后端行操作采用相同规则；整文档提交漏清过期关联或连线时拒绝保存，不静默改写提交文档。后端行更新回执补充实际 `deletedEdgeIds`，助手变更摘要及整轮撤销同时处理这些连线。专项集成测试验证同一操作重放不重复执行、撤销能恢复行和连线，未削弱版本、归属或任务绑定检查。

项目样式统一隐藏全局 Toast，不能用临时消息作为明确反馈。因此过期行持久保存 `imageBindingStale=true`，在画布及全屏编辑器显示“旧图和任务已保留，请重新生成分镜图”。重新创建或明确连接图片后清除标记。该字段位于既有画布 JSON，无新增数据表或迁移；不把旧任务错误取消、失败或自动重新生成。
