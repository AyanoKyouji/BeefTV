## 发现与修复

### 1. 生成请求执行中退出，恢复后丢失提交未知状态

复现：向本机受控图片端点提交一个同步请求，在收到请求但尚未返回结果时 SIGKILL 测试后端。新进程启动后等待真实任务租约到期。

修复前，路由层正确识别历史请求可能已提交，没有第二次生成 POST；但任务终态写成 `failed / 路由准备失败`。原因是 `taskTerminalCoordinator.markPreparationFailure` 忽略了调用方传入的 `uncertain`，把历史未知提交与首次、本地未提交的准备失败混在一起。原测试只断言失败和零重发，没有检查持久化 stage、公开 errorCode 或手动重试边界。

修复仅在明确的 `uncertain=true` 时写入 `submission_unknown`。一般本地准备失败仍保留原分类，DEV-008 的“未发出请求”语义不变。

验证：先增强原有租约恢复集成测试，得到修复前失败；修改后，集成测试验证 `submission_unknown`、公开 `submission_uncertain` 和手动重试拒绝。另用全新任务实际执行 SIGKILL 与重启，结果为：

| 项 | 修复后实测 |
| --- | --- |
| Task | `c3fecbe8…d40b080`，复用原 ID |
| status / stage / errorCode | `failed / submission_unknown / submission_uncertain` |
| 用户提示 | 提交结果尚未确认，上游任务可能仍在执行；先查询原任务，不立即重新提交 |
| 界面 | 可查看原任务、复制排查信息，没有“重新生成”操作 |
| 手动重试 | HTTP 400，业务拒绝 |
| 图片协议 POST | 退出前 1 次，重启后 0 次 |
| 结果 | 没有成功产物；`FAILED_PERMANENT` 表示本地交付合同禁止重试，不能解释为供应商已确认生成失败 |

没有修改修复前任务记录来制造修复后证据；两个任务分别留存。

### 2. 快照采集器漏比对分镜字段

`Inspect-Saved-Project.mjs` 只投影少量行字段，漏掉 `camera`、`durationSeconds`、`videoMotionPrompt` 等，而且读取了当前类型不存在的 `videoPrompt`。受控复现中，在相同 revision 下改变 `camera`，旧采集器仍返回 PASS。此处是在验证采集器能否发现字段丢失，不是声称正式写路径会绕过 revision。

修复：保留完整分镜行与连接；新增 `schemaVersion=2` 和对整个持久化画布文档计算的 `documentSha256`。对象键顺序规范化，数组顺序仍参与比较。另拒绝 `--out` 与 `--compare` 相同，避免覆盖基准后自我对照。

新增测试覆盖字段、节点、归属和连接变化、对象键重排、中文含空格目录、基准保护及旧快照拒绝。旧快照缺少全文档摘要，必须重采 before/after；不能根据工具升级追认历史全文档一致。摘要也不代替媒体文件字节哈希。

## 方法、成本与过程记录

测试复制既有 DEV-012 数据到独立开发数据目录，未操作日常数据。Go/Vite 及其子进程使用 macOS 策略只允许 localhost 出站，外网连接探针被系统拒绝；浏览器也拦截外网请求。图片内容复用 DEV-009 已有真实 JPEG，SHA-256 `8bfba550…a984b4a`。

含控制器失败尝试在内，本轮浏览器运行共 8 次本机图片协议 POST（6 次交付，2 次在请求未返回时故障终止）；远程文本、图片、视频模型调用均为 0。单元测试自己的本机假服务请求单列于测试日志，不计成真实模型调用。

控制器的缺少文本配置/会话夹具、页面首次规范化导致快照过期、跨重启旧 HTTP 连接、误用 SQL 列名，以及误把未知终态预期成 `NOT_AVAILABLE` 等失败均保留。最后一项按既有 `task.ResultState` 合同改为检查非 READY，未改动产品合同以迎合断言。最终补核读取实际 SQLite schema，结果表 identity 从 payload 的 outputIndex 获取；没有重复 output。

本轮不关闭完整 AT/E2E，不执行 DEV-018/019 的真实模型业务验收。DEV-017 修复版平台回归及最终 Windows E2E 仍待执行。本轮隔离测试进程与三个测试端口均已关闭；复测前已运行的日常后端及其 Agent 宿主未停止，也未变更其数据。该既有进程仍运行旧代码，使用修复需在后续正常重启时加载新版本。原始日志、截图、数据库、媒体及配置仅在本机保留。
