## 发现与修复

修复前，在本机文本服务实际收到官方宿主请求后暂停响应，页面处于“助手正在处理…”并有停止按钮。连续三个带时间的画面及浏览器动画状态均没有无限循环的处理动画；原样式只有侧栏展开的 220 ms 入场动画，不能表示持续处理状态。此问题不影响已有文字和停止操作，但不满足 AT007 的基础动画要求。

修复复用现有 `streaming`、回执恢复、对话读取、失败/取消、提案处理和执行中集合：

- Agent 标识只在处理中或等待最终回执时做轻量呼吸动画，结束、等待确认、失败或停止后静止。
- 显示“就绪”“处理中”“正在确认结果”“等待确认”“本轮未完成”“已停止”等状态；历史未读、宿主不可用不误称就绪。新处理中状态优先于旧错误或旧提案。
- 提案确认提交和已受理生成任务分别显示“正在提交生成”“生成任务执行中”，与 Agent 自身活动分开。生成执行中不继续播放 Agent 动画。
- 使用现有语义颜色与字号，提供状态语义及 polite 播报；`prefers-reduced-motion` 下关闭处理动画，仍保留文字。

改动仅在前端文案/状态映射、侧栏展示和局部 CSS，加专项状态优先级测试。未修改任务、授权、生成确认、Agent 运行循环或模型协议。
