# 开发与跨平台验证约定

- 生效日期：2026-10-20；最新调整：2026-10-21（Asia/Shanghai）。
- 依据：用户要求后续直接在本机 Mac 开发和运行验证；独立复测后进一步要求后续直接在 Mac 推进，减少两台机器之间的交接。
- 适用范围：第六阶段后续开发及 DEV-018/019 完整业务闭环。Windows 检查集中到最终交付前，未执行项继续保留，不阻塞 Mac 功能验收。

## 1. 日常开发

以 `${BEEFTV_REPO}` 为主开发工作区，在 Mac 上完成代码修改、组件检查、实际业务操作、模型接入及保存/恢复验证。每项报告记录实际平台和运行方式。

React/Go 开发联调适用于页面、数据和业务流程；涉及 Wails 绑定、窗口、文件选择、桌面资源定位或打包时，应在 Mac 原生客户端验证相关能力。既有 Mac 原生安装规则继续有效，正式本机应用路径为 `/Applications/BeefTV.app`，按仓库现有脚本更新。

DEV-002 现有证据是浏览器界面连接 Go 桌面组合根，以及独立 Node 宿主测试；尚不能据此称 Mac 原生窗口已验证。后续首次需要原生能力时补齐实际启动结果。无需每完成一个 DEV 都重新发送 Windows 源码包或要求用户在两台机器间切换。
